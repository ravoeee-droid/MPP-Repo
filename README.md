## Absolute rules

- The chosen generated mockups are the visual source of truth.
- No random redesign or new design direction.
- Keep Ivory / Ink / Signal-Citron.
- No generic SaaS cards, gradient-orb style, fake luxury, random glassmorphism or unrelated visual trends.
- No invented reviews, metrics, customers, testimonials, certifications, BAFA/TÜV claims or case results.
- Mobile is designed intentionally, not merely stacked desktop.
- Motion enhances the locked design; it does not replace it.
- Each major section must pass desktop + mobile visual QA before lock.
- No final production deploy without explicit human approval.
