# MPP MOTION SYSTEM

## Principle
Motion explains the strategy. It is not decoration.

## Recommended stack
- Lenis for controlled smooth scrolling if testing confirms value
- GSAP + ScrollTrigger for scroll-linked storytelling
- CSS transforms/opacity for light interactions
- optional Motion for React for local state transitions
- Three.js/WebGL only for one justified signature moment with fallback

## Signature motion
Hero:
- masked headline reveal
- subtle founder image depth
- Operating Line draw-in
- restrained magnetic CTA

Problem:
- friction / slight misalignment → ordered grid

Operating System:
- sticky/pinned story
- scroll-synchronous line draw
- nodes activate PEOPLE → PERFORMANCE → SYSTEMS → GROWTH
- copy and visual state change in sync

Services:
- image-mask reveals
- precise hover response
- no generic cards simply floating up

Diagnostic:
- real answer states
- live profile transitions
- progress
- result-state morph

Process:
- linked stages
- current stage activation tied to scroll

Cases:
- editorial transitions
- optional controlled horizontal storytelling on desktop only if mobile remains strong

Founder:
- subtle depth
- quote reveal
- no theatrical 3D

Final CTA:
- strongest micro-interaction after Hero
- Operating Line reaches Growth node

## Global rules
- reduced-motion fallback required
- no animation on every paragraph
- no permanent motion hurting readability
- target smooth 60fps feel
- prefer transform / opacity
- measure before keeping blur / filters / WebGL
- mobile motion is redesigned, not merely disabled
