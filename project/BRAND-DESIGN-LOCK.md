# BRAND + DESIGN LOCK

## Palette
- Ivory: `#F4F0E8`
- Ink: `#111315`
- Signal Citron: `#DBFF3E`
- Graphite: `#6E7174`
- Mist: `#D9DAD5`

## Typography direction
- large editorial display type for statements
- clean modern grotesk for UI/body/navigation
- strong hierarchy
- small uppercase labels / eyebrows
- intentional line-height / tracking
- no random trend mixing

Final font families may be selected during implementation only if they closely match the chosen mockups and pass licensing/performance requirements.

## Layout
- 12-column desktop grid
- deliberate asymmetry
- large but intentional negative space
- thin rules / lines
- editorial image/type tension
- each section may have unique composition while sharing one visual grammar

## UI
Primary CTA: Signal Citron / Ink  
Secondary: restrained outline / transparent  
Text links: arrow + precise micro motion

Avoid excessive SaaS-style rounding.

## Photography
Priority:
1. real founder/company material
2. rights-cleared client/social assets
3. supporting AI imagery not presented as proof
4. licensed stock only when relevant

Style:
- documentary
- natural daylight
- real conversations
- close human presence
- modern SME/consulting setting
- restrained styling
- subtle depth of field
- no forced handshakes / fake celebrations

## Visual motifs
1. Operating Line
2. Citron nodes
3. editorial rules
4. friction → clarity transformation
5. data/system language used sparingly

## Regression lock
Do not replace this system during later “polish” passes.
