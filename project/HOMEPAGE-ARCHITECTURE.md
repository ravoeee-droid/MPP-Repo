# HOMEPAGE ARCHITECTURE

Every section gets one dominant job: UNDERSTAND, BELIEVE, WANT or ACT.

1. Hero — UNDERSTAND + ACT  
   “Die richtigen Menschen sind erst der Anfang.” Founder-led image. Primary CTA + secondary approach/diagnostic.

2. Immediate Trust — BELIEVE  
   Verified reviews / references / funding status / confidentiality. No fake badges.

3. Problem — UNDERSTAND  
   “Recruiting allein reicht nicht.” People / Performance / Systems friction.

4. MPP Operating System — UNDERSTAND + WANT  
   PEOPLE → PERFORMANCE → SYSTEMS → GROWTH

5. Services — UNDERSTAND  
   People / Recruiting, Performance, Systems / Organisation

6. Growth Diagnostic — ACT  
   5-question interactive diagnostic with live profile.

7. Recruiting Proof — BELIEVE  
   Contextual recruiting case / process / evidence.

8. Performance Proof — BELIEVE  
   Leadership / sales / performance evidence.

9. Systems Proof — BELIEVE  
   Organisation / roles / processes evidence.

10. Founder — BELIEVE  
    Personal authority, philosophy, real experience.

11. Process — UNDERSTAND  
    Analyse → Klarheit → Umsetzung → Entwicklung

12. Case Study Library — BELIEVE  
    People / Performance / Systems cases. Verified only.

13. Reviews — BELIEVE  
    Google / real customer voice.

14. Client References — BELIEVE  
    Real approved logos only.

15. Funding / Credentials — BELIEVE  
    BAFA / TÜV / ISO / IHK / memberships only if exact status is verified.

16. Confidentiality — BELIEVE  
    Privacy, discretion, professional handling.

17. Fit — WANT  
    For whom MPP is right / not right.

18. Insights — BELIEVE  
    Thought leadership / SEO / authority.

19. FAQ — BELIEVE  
    Handle real objections.

20. Final CTA — ACT  
    Explain exactly what happens in the first conversation.

21. Footer  
    Minimal, complete, legal, contact, final Operating Line node.
