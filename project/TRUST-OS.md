# MPP TRUST OS

## Rule
Trust belongs next to the doubt, not in one giant badge wall.

## Proof order
1. real person
2. real result
3. real process
4. real reference
5. institutional proof
6. risk reduction

## Required proof types
- founder credibility
- verified Google reviews
- real case studies
- approved client logos
- process transparency
- confidentiality/privacy
- funding/certifications only when exact status is verified
- FAQ / objections
- direct human contact

## Context placement
Recruiting claim → recruiting proof beside/after it.  
Performance claim → performance case beside/after it.  
Systems claim → systems evidence beside/after it.  
Booking CTA → founder identity + what happens next + review proof.

## Credentials
Never publish BAFA/TÜV/ISO/IHK/award/member claims unless entity, scope, current validity and permitted logo usage are verified.

Internal states:
- VERIFIED
- NEEDS CLIENT EVIDENCE
- NOT APPLICABLE
- REMOVE

## Fake-proof blocker
Never invent:
- stars / review count
- customer quote or avatar
- customer logo
- placement rate
- revenue uplift
- time-to-hire
- number of placements
- certifications / awards
