# BUILD RUNBOOK — SECTION-BY-SECTION GOLDEN MASTER

## Principle
Do not build the full page in one pass. Quality may not decay from section 1 to section 20.

## Wave 1 — establish the grammar
1. Foundation
2. Header
3. Hero
4. Operating System
5. Services
6. Growth Diagnostic

## Per-section loop
For EACH major section:

1. Read section purpose + reference mockup
2. Build static desktop composition
3. Render at ~1440 px
4. Compare to Golden Master
5. Fix layout / typography / image crop / rhythm
6. Build dedicated mobile composition
7. Render at 390 / 430 px
8. Fix mobile
9. Add motion
10. Test reduced motion
11. Performance check
12. Trust/fact check
13. LOCK section

Only then move on.

## Section Quality Gate
Every section must pass:
- Purpose
- Story
- Art Direction
- Brand recognition without logo
- Typography
- Image quality / crop
- Trust / proof integrity
- Conversion logic
- Motion
- Desktop
- Mobile
- Performance
- Facts
- Accessibility

## Scope lock
A local fix is not permission for redesign.

Preserve:
- chosen visual references
- approved copy
- approved images
- motion language
- canonical logo
- neighboring sections
- mobile quality

## Release rule
Preview builds may be used for QA.

NO final production deploy, domain switch or release status without explicit human approval.
